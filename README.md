# Borda

Console local para a borda de uma rede. Mostra por onde a casa está saindo, se a saída reserva por USB está pronta, e quem está na LAN. O RouterOS continua dono do resto.

O desenvolvimento ainda não começou. O plano, o que fica de fora e as decisões que bloqueiam o código estão em [docs/plano-de-desenvolvimento.md](docs/plano-de-desenvolvimento.md).
